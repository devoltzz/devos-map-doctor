What this is

Devo's Map Doctor in your browser: the same program as the download for Windows and Linux, run here. It opens protected Warcraft III maps, fixes what stops them on Reforged 3.0, prepares them for the World Editor and ports the maps of the KK and M16 platforms. It also checks whether a map runs on Reforged or on an older game, adds cheat packs and quality of life edits, exports and imports translations, shows the files of a map (with a 3D preview of its models) and its script, and helps find out why a map fails in the game (Diagnose reads the crash reports, the logs of a diagnostic copy and the replays). The page is in English and 16 other languages.

Privacy

  • Your map never leaves your computer. Every step runs inside this page (Python compiled to WebAssembly); nothing you open is sent anywhere. What the Doctor writes comes back to you as a download.
  • No account, no cookies, no analytics, no ads. The server keeps no access log.
  • The page remembers your settings in this browser only (local storage), and keeps its own files in the browser cache so it works offline.
  • "Report a problem" opens a GitHub issue with the report filled in, in a new tab: you read it and decide whether to send it.

What the page downloads

  • The program itself: the Doctor's engine, Python (Pyodide) with numpy and Pillow, and pjass (the JASS checker), about 20 MB, once.
  • The game data the engine reads (Warcraft III's object tables, TriggerData and the game scripts), about 3 MB: the program for Windows and Linux reads them from your installed game.
  • The file name index (62 MB), only if you accept it: it recovers the names of files in protected maps.

Limits

  • Chrome, Edge and Firefox on a computer. Safari and phones may work, slowly or not at all.
  • Very big maps (above 450 MB) need more memory than a browser gives a page: use the program for Windows or Linux.
  • The browser is slower than the program (about 1.5 times).
  • Only in the program for Windows and Linux: the local machine translation, the text in the images (OCR) and the offer to share the file names the shared name list does not know.
  • The checks that need the game's own file list (map files at the game's own paths, model paths that resolve to nothing) run only in the program with the game installed.
  • Diagnose cannot see the folders the game writes to: choose the log, the crash report or the replay yourself (Documents\Warcraft III\CustomMapData\DevosMapDoctor, Documents\Warcraft III\Errors and the Replays folder of your account under Documents\Warcraft III\BattleNet).
